# 快速开始

适用于 coding远程 2.2.5：Windows x64 助手与 Android 8.0+ App。安装包名称、版本与下载入口见 [README](../README.md#安装与连接)。

## 1. 准备电脑与手机

在同一 Windows 用户下安装并登录 Claude Desktop、Codex Desktop 或 DeepSeek Harness，至少准备其中一个。运行 Windows 助手；安装包自带运行时，无需另装 Python。Android 安装 APK，首次扫码时允许相机权限。

## 2. 临时连接

1. 在电脑助手选择“临时连接”。
2. 等待 HTTPS 入口与二维码生成，再用手机 App 扫码。
3. 配对成功后打开对应客户端页面，即可查看会话。

临时连接不需要域名、服务器或 Tailscale。二维码 5 分钟有效且只能使用一次；配对后的临时凭据有效期为 24 小时。主动关闭临时入口或退出后台服务会使其失效，届时重新扫码即可；隧道自行中断不会吊销凭据，但临时地址变化后仍需重新扫码。当前原生版通过二维码配对，不使用旧网页版本的手机登录密码。

## 3. 连接桌面客户端

| 客户端 | 操作 |
| --- | --- |
| Codex | 保持 Codex Desktop 运行，在手机 Codex 页面刷新并选择会话。 |
| Claude | 点击手机 Claude 页面标题，选择“启动”。助手会启用 `allowDevTools`，打开 Console 并自动输入连接脚本；输入期间保持焦点，按 Esc 可中止。收到有效回执后自动关闭 DevTools，并最小化助手。 |
| DeepSeek Harness | 助手为已安装的 Harness 配置本地 Host 插件；首次配置后正常重启 Harness，再回手机刷新。 |

Claude 仍需遵守桌面项目目录信任要求。连接失败时助手会保留诊断窗口，可以检查后重试；不要在自动输入期间切换焦点。手机各客户端标题中的启动、关闭和重启只作用于对应客户端；Windows 助手的窗口控制位于手机设置中。

## 4. 设置长期连接

自有服务器：按[部署说明](azure-server.md)准备 HTTPS 入口后，在电脑“应用设置 → SSH连接”填写 HTTPS 地址、SSH 别名及远端端口，点击“保存并连接”，手机扫描生成的二维码即可。手机无需安装 Tailscale，电脑使用系统 OpenSSH。

也可以使用 Tailscale：

1. 在电脑“应用设置 → 永久连接”登录 网络账户。
2. 在手机“设置 → 永久连接”登录同一 设备网络。
3. 等待两端网络就绪，在电脑切换到“永久连接”，再扫码一次。

内置组件无需额外安装 Tailscale App，但仍需 网络账号与网络服务；电脑也保留外部 Tailscale 兼容方式。内置节点与系统 Tailscale 节点是不同身份，切换方式后应重新扫码。更多说明见[设备网络](tailscale-integration.md)。

手机按入口分别保存凭据。线路中断时，只会尝试该电脑已保存的其他扫码线路；临时地址失效后需要重新扫码。在“设置 → 已连接电脑”中管理和移除连接。

## 5. 日常操作与升级

- 会话输入区可选模型、思考强度、审批和插件。执行中有输入时点击发送会加入队列，没有输入时点击停止当前任务。
- 会话向右滑动打开 Git，向左滑动或按返回键回到会话。
- 从会话信息进入工作目录，或点击正文文件链接预览文件；图片可直接点击查看。
- 任务完成通知与悬浮窗需要在设置中开启并授予对应系统权限。不显示常驻监控通知；系统省电或强制停止仍可能终止后台进程，回到 App 后恢复连接。
- Claude / Codex 会话中长按已发送的用户消息，选择“撤回编辑再发送”；发送前可以取消，取消会恢复原输入草稿。

关闭 Windows 窗口只会隐藏助手，后台服务继续运行。再次运行 EXE、使用托盘或手机设置可重新显示窗口。彻底退出使用系统托盘菜单；服务停止后手机无法远程唤起。

升级时先彻底退出旧助手，再打开新版 EXE。Android 使用相同签名覆盖安装以保留绑定；若签名不兼容，先保留需要的应用内文件再处理，不要直接卸载。建议两端使用配套版本。

遇到问题可查看[常见问题](faq.md)；全部手机操作见[功能说明](android-ui.md)。

## 2.2.5 界面与设置

Windows 侧栏保留概览、账号与模型、查看日志及应用设置四页。概览是扫码首页，可选择临时扫码、永久连接或SSH连接。手机从会话信息打开 Git、工作目录与独立终端。

手机只支持扫码连接。列表底部固定显示 Claude、Codex、DeepSeek 应用图标；进入会话后底栏隐藏，应用标识显示在回复旁。设置页提供分组入口和详情返回。

API 连接可加密保存并读取可用模型；SSH/WSL 终端依赖电脑已经配置的环境。Windows 已移除桌面宠物；手机宠物在 Android 设置中管理。
