# 2.2.4 修订与验证

2026-11-10。本版新增自有服务器永久绑定，并修复手机会话页与悬浮窗长时间不更新。Windows / Android 需同时升级。

## 固定 HTTPS 入口

- Windows 概览增加第三种连接方式；应用设置可保存 HTTPS 地址、SSH 主机别名和远端转发端口。
- 系统 OpenSSH 以回环地址建立反向转发，自动重连；只有转发成功且 HTTPS 网关身份与本机一致后才显示二维码。
- 自有服务器使用原有永久配对协议，保留 Tailscale 和临时入口的凭据与二维码隔离、撤销和同电脑线路切换。
- Android 按入口区分永久 HTTPS、Tailscale 和临时连接，不把所有 HTTPS 都显示为临时连接。
- Nginx 关闭 SSE 缓冲和写请求代理重试。服务器部署与维护见[部署说明](azure-server.md)。

## 会话与悬浮窗刷新

- Windows 文件通知可能遗漏；Codex 列表定期刷新，运行中的会话约每秒重新读取，空闲会话约每四秒重新读取，不再只依赖元数据变化。
- 服务器对已核验但未变化的数据发送轻量 checkpoint。它不会挤掉慢客户端尚未读取的完整数据。
- Android 分别追踪每种数据的新鲜度。仅有传输心跳不会重置计时，超过 18 秒未核验时补查会话与状态，正常未变化时无需反复渲染。
- 状态采集为三个客户端分别分配有界任务，一个慢客户端不再拖住其余客户端和悬浮窗。
- 任务监控以前台服务运行，共用实时连接；启用通知或悬浮窗后显示持续监控通知，关闭后清理服务及系统作业。
- 延迟到达的任务状态会检查当前电脑和凭据，防止切换电脑后应用上一台的数据。

合成测试测得的耗时不代表实际跨网延迟承诺。尚未在用户实体手机上验证。系统省电、强制停止、断网及 Android 15 的 dataSync 前台服务时长限制仍可能中断后台监控；回到 App 可恢复，系统作业提供周期补查。

服务器基础设施和隔离公网端到端验证已完成。实际电脑使用时需在新版助手中填写服务器信息并“保存并连接”，再由实体手机扫码。
