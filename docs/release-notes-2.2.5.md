# coding远程 2.2.5

从 2.1.1 到 2.2.5 的累计更新。Windows 与 Android 需要同时更新。

## 实时更新改为事件驱动

会话、状态与队列改为源事件触发，手机取消定时内容补查和「远程任务监控运行中」常驻通知。`LiveHub` 以条件变量驱动采集：Codex 用桌面 IPC 回调与 Windows 文件通知，Claude 用原生 `onEvent`／`onToolPermissionRequest` 回调与签名事件版本，DeepSeek 用持久化文件通知。内容未变不重复发布，采集期间的新事件会触发下一轮。传输保活与超时检测仅用于断线恢复，不再刷新会话或连接状态界面。

健康连接下不再轮询，SSE 通道以心跳判断存活；缺失初始快照或通道失效时仍回退。本地合成更新实测约 103–187 ms，为单次观测值。

## 连接入口

统一为**临时连接**、**永久连接**、**SSH连接**三种：

- **临时连接**：Cloudflare Quick Tunnel，无需域名，24 小时有效。
- **永久连接**：设备私网直连或内置 Tailscale，WireGuard 加密。
- **SSH连接**：自有域名 HTTPS，SSH 反向转发到电脑，支持自动重连、网关身份验证与独立永久凭据。

扫码流程细化了 DNS、TLS、连接重置以及服务器无法连接电脑的 502／504 提示。两端仅保留扫码配对，删除局域网、手机 SSH 与自定义入口；网关改为独占监听，端口被占用时自动选择空闲端口并保存。所有二维码 5 分钟有效、单次使用；当前线路已有有效绑定时不再显示或刷新二维码。

## 手机端

- **实时与会话**：消息分片保留原始编辑标识；撤回后等待前一轮停止并连续确认空闲再重发，同一请求不会执行两次。推送更新当前会话，迟到的旧 HTTP 响应不覆盖新消息。
- **撤回编辑再发送**：长按用户消息，原文回到输入框；确认后才由电脑撤回该轮及后续消息并重新执行。已执行的文件修改不会自动回滚；编辑期间历史变化时服务端拒绝覆盖。
- **界面**：移除输入框上方核对条与会话流执行汇总条，执行详情改为固定位置向上展开；会话信息底部把 Git、工作目录、终端合成一行；选择框、操作菜单、提示框与文件预览居中。
- **外观**：改为 Catppuccin、Tokyo Night、Everforest 三套配色，支持浅色／深色／跟随系统、列表与消息背景分别设置不透明度；新增青庭、海湾、陶土、墨白色彩风格，同时调整表面、圆角、边框与阅读字体行距。来源见 [配色说明](docs/mobile-palettes.md)。
- **宠物与悬浮窗**：宠物与气泡使用独立窗口，打开和关闭气泡不改变宠物坐标；新增耳朵、爪子、眨眼及机器人手部动作，按状态播放且整体位置固定。移除常驻通知，改用绑定服务共享事件连接。
- **预览**：原生 Markdown 表格支持横向滚动、对齐与分页表头；图片默认缩略图、支持原图缩放与重试；新增 DOCX／PPTX／XLSX 预览。
- **设置**：重写为搜索、分组行、当前值、独立详情页与返回导航；连接详情统一为设置行。

## 桌面端

- 首页仅保留扫码连接，已有有效绑定时隐藏二维码与刷新按钮。
- 移除工作台、通知中心、桌面宠物与外观设置，保留概览、账号与模型、日志、设置。
- 操作仅保留关闭与重启；新增「任务结束自动关机」，仅在观察到任务运行并全部结束、无待处理审批和待发队列时安排 60 秒倒计时，可取消，助手重启后默认关闭。
- 减少页面重建、无关状态采集与日志主线程读取，修复后台垃圾回收等待 Tk 导致的拖动卡顿。
- Claude 桥接接收原生流式文字事件并合并到手机快照，结束后用完整记录替换临时文字；不传输原始思考内容。

## 安全与其他修复

- **路径校验**：文件读取改用 `absolute_inside()`，拒绝空字节与 UNC／扩展长度前缀，要求解析后确实位于允许根目录。
- **隧道二进制**：启动 `cloudflared` 前校验 SHA-256 与 `bin/cloudflared.sha256` 一致，不匹配即拒绝执行。
- **队列**：单一连接加锁内读-改-提交，新增 `dispatch_lock` 串行化派发，顺序改为 `rowid` 插入序；`close()` 幂等并清理 WAL 残留；静默失败补日志。
- **电脑身份**：轮询的读写都校验 `computerId`，不再只在 POST 时校验。
- **Git**：先解析会话目录，无仓库时回退到会话关联的项目目录，普通目录给出中文说明。

## 安装

1. Windows 先彻底退出旧助手（系统托盘菜单），再运行新版。
2. Android 使用相同签名的 APK 覆盖安装以保留绑定；从 2.1.1 升级后如提示连接失败，请在电脑保存新的 HTTPS 地址并重新生成二维码扫码一次。

## 已知边界

- 电脑休眠、关机或后台服务退出后手机无法访问，也无法远程启动已停止的助手。
- 系统省电或强制停止可能终止 Android 后台进程，回到 App 后恢复连接。
- 桌面客户端升级可能改变内部接口；Claude 复杂嵌套表单与目标自动连续执行仍需进一步验证。
- 仅在 Windows 与 Android 交付，无 iOS 原生版本。

验证范围与逐版细节见仓库 `docs/revision-2.2.5.md`、`docs/releases.md`。模拟器与隔离数据结果不覆盖实体设备厂商后台限制与完整公网链路。
