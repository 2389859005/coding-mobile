# 2.2.5 修订与验证

## 连接与实时更新

Android 公网 HTTPS 使用系统网络连接；私网仍使用独立直连或内置 Tailscale。TLS、电脑身份及配对验证均保留。扫码错误细分 DNS、TLS、连接重置以及服务器无法连接电脑的 502/504。

本次原 Azure cloudapp 域名在原生 TLS 路径发生重置；同一 IP 的新域名完成正常证书校验。已为新域名配置证书及 Nginx，并保留旧入口。实体手机对新域名的 `/healthz` 返回 200；切换真实电脑前网关返回 502。详见[部署说明](azure-server.md)。

LiveHub 使用源事件和条件变量触发采集，没有健康状态下的定时内容采集或检查点刷新。Codex 使用桌面 IPC 回调及 Windows 文件通知；Claude 文件桥接使用已核实的原生 onEvent/onToolPermissionRequest 回调和签名事件版本；DeepSeek 使用持久化文件通知及待回答事项事件标记。未变化内容不重复发布，读取期间的新事件会触发下一次采集。慢来源已完成的状态仍先显示，避免连续输出让结果永久等待。

任务队列由源事件、用户操作和一次性的派发确认期限唤醒。失败重试属于恢复操作。手机初次进入、手动操作及重连仍可读取当前快照；稳定连接不进行定时内容补查。旧 SSE 接口也共用事件源。传输保活与超时检测仅用于断线恢复，不触发会话或连接状态界面刷新。Claude 文件命令收发仍使用其既有本地邮箱机制，存活时间戳不触发会话采集。

## 通知与后台

移除“远程任务监控运行中”常驻通知、前台服务启动和周期性后台补查作业。App 与悬浮窗通过绑定服务共享事件连接。用户启用的任务完成、待审批、待回答通知继续保留。Android 回收或强制停止进程后不保证后台连接，重新打开 App 可恢复。

## 本轮追加修订（版本仍为 2.2.5）

- Claude 桥接接收原生流式文字事件，合并到手机快照；消息结束后由完整记录替换临时文字。中途恢复连接时也接收后续片段。保留原生可见文字，不传输原始思考内容。会话、记录与用量改为一次本地请求读取，缩短本地命令等待。
- 手机发送后读取当前内容；推送更新当前会话，迟到的旧 HTTP 响应不覆盖新消息。历史阅读、滚动和选择文字时也处理任务完成状态。显式空闲状态优先于 Claude 保持运行的进程状态。
- 消息分片保留原始编辑标识。Claude 撤回后等待前一轮停止完成并连续确认空闲，再重新发送；同一请求不会执行两次。
- 移除输入框上方核对条与会话流里的执行汇总条；结果不确定时保留原操作到执行详情。执行详情保持固定位置、向上展开，保留输入草稿和内部滚动位置。消息顶部不显示目录。
- 会话信息底部的 Git 管理、工作目录、终端合成一行。设置连接详情统一使用设置行。选择框、操作菜单、提示框和文件预览居中。
- 桌面宠物与气泡使用独立窗口；打开、更新和关闭气泡不改变宠物窗口坐标，气泡显示回复内容。
- 设置首页仅保留任务通知开关，移除通知详情与记录入口。色彩风格改为青庭、海湾、陶土、墨白，同时改变表面、圆角、边框和阅读字体／行距。
- 两端连接入口统一为临时连接、永久连接、SSH连接；手机连接状态使用已连接／已断开。
- 桌面助手操作仅保留关闭和重启；电源新增任务结束自动关机。仅在观察到任务运行并全部结束、没有待处理审批和待发／结果未知队列时安排 60 秒倒计时；可取消，助手重启后默认关闭。

## 连接输入与手机设置追加修订

- Claude Console 输入优先使用已验证输入框的整段文本接口；兼容路径改为较大的有界输入批次，减少反复跨进程读取焦点造成的停顿。提交前核对完整脚本，输入日志附带阶段耗时。
- 桥接缓存已验证工作目录的会话标识，助手和 Claude 重启后的脚本都会使用最新缓存，减少全量历史目录检查。新建桥接使用已核实的 `withoutFirstMessage` 参数；会话已注册时即可建立文件桥接，无需一直等待模型初始化请求结束。失败或取消仍清理订阅，待完成的初始化不会重复创建会话。
- 首次初始化不再在 15 秒时误报连接失败。等待回执期间释放应用操作锁，保留明确的初始化状态；停止、重启入口仍可响应。最终超过初始化期限才提示连接错误。
- DeepSeek 状态来自本地带鉴权的 Host 健康回执；兼容仍在运行的旧 Host，以其列表回执验证连接。修复应用状态一直返回 `connected=false`，源事件同时刷新应用状态。
- SSH 固定入口经电脑身份核验后，修复旧版误存为临时模式的未过期绑定。手机重新打开时选择同一电脑最近保存的永久线路，读取设备回执时同步连接类型。撤销或已过期的凭据不会被恢复；这些情况仍需重新配对一次。
- 会话列表条目去掉目录副标题，会话消息顶部继续只显示标题和状态；项目目录仍可在项目分组和会话详情查看。
- 设置首页“连接”分组包含“连接详情”和扫码入口；永久连接网络设置合入连接详情，详情移除扫码入口及当前线路的重复条目。补齐通知、解除绑定、网络、背景、电源等图标，底部版本号居中。
- “外观与背景”分为“外观与主题”“背景与阅读”。旧四种主题移除，改为三套只有配色差异的 Catppuccin、Tokyo Night、Everforest；每套分别定义组件、文字、状态、代码及差异色，字体、圆角和排版一致。公开来源和角色表见 [配色说明](mobile-palettes.md)。
- 左上角客户端标题展开页面内操作列表，左侧对齐、宽度最多 176dp，并受可用宽度约束。再次点击标题或返回键收起，不创建弹窗。
