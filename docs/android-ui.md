# 手机功能说明

适用于 Android 原生版 2.2.5。首次配对与客户端接入见[快速开始](quick-start.md)，本版改动和验证见[修订记录](revision-2.2.5.md)。

连接支持临时 HTTPS、永久连接和SSH连接。自有服务器入口由 Windows 助手配置，手机扫描对应二维码即可。

## 会话与项目

列表底部固定显示 Claude、ChatGPT、DeepSeek 应用图标，进入会话后隐藏底栏，在回复旁显示对应应用图标。每个列表独立提供新建、刷新、搜索和项目分组，Claude 按会话所属的项目目录分组，不按会话当前的工作目录。会话条目不显示目录副标题，项目分组和会话详情仍可查看目录；执行中的 ChatGPT / DeepSeek 会话显示运行状态。归档会话集中在列表末尾“归档”的弹窗中。

点击客户端页标题可启动、关闭或重启该客户端。新建 Claude 会话可选 Code 或 Work（Cowork）。明确点击 ChatGPT 会话时会打开对应桌面任务，后台读取和返回前台不会反复切换桌面。

## 输入与任务控制

| 入口 | 功能 |
| --- | --- |
| 模型与思考强度 | 根据后端能力选择，保存后回读核对。Claude 选项不全时可在桌面打开模型菜单后刷新。 |
| 审批 | 显示后端提供的权限选项；桌面审批和提问可在手机回复，支持选项、自由输入和基础表单。 |
| 插件 | ChatGPT 按已安装插件整包选择；DeepSeek 显示技能与组件状态，具体选项取决于桌面。 |
| 模式 | ChatGPT 支持普通／计划模式，以及目标设置、暂停、继续和清除；Token 预算仅在填写时提交。 |
| 附件 | 单次最多四张图片，支持只发图片。 |
| 发送／停止 | 执行中无输入时停止，有输入时加入队列。队列可撤回编辑、删除或立即发送。提交结果不确定时在执行详情中保留原操作，供用户查询或处理；输入框上方不再显示核对条。 |

队列保存在电脑，任务结束后依次执行。写入使用独立请求编号，结果不确定时暂停后续发送，通过原请求查询结果，避免重复任务。

Claude / ChatGPT 已发送的用户消息可长按“撤回编辑再发送”。开始编辑时保留普通草稿，原文放入输入框；取消恢复原草稿，点击发送才撤回该轮及后续记录并重新执行。正在运行的任务需先停止；编辑期间历史变化会拒绝提交。已执行的文件修改不自动回滚。ChatGPT 保留原附件；含图片的 Claude 消息暂需在电脑编辑。两种编辑均不支持添加新附件，结果未知时不自动重发。

发送按钮外圈顺时针显示上下文占用，长按可查看已用／最大 tokens；圆环始终可见，75% 转琥珀色、90% 转红色。只有可信统计才显示用量：ChatGPT 使用最新一轮统计，Claude 接口可能返回空值，DeepSeek 当前没有可用统计；未知显示灰环与“—”。

## 阅读与执行记录

消息支持 Markdown、围栏代码、diff、横向滚动表格与图片。长表格在分页时重复表头，保留全部行。长按用户消息或助手回答使用统一的底部操作弹层，可复制、选择、引用或分享；选字期间暂缓重绘。

执行记录按需折叠，保留可见思考摘要、计划、文件变化和实际工具内容；ChatGPT 命令及通用通信包装被过滤。会话流不再显示额外执行汇总条。“执行详情”保持在输入区上方，从固定位置向上展开，中央显示步骤数、文件数、绿色增加数与红色删除数。文件变更标题只占一行，过长路径从中间省略。统计来自执行记录累计变化，不等于 Git 的最终净差异。

ChatGPT 的图片查看工具及编排调用、Claude Read 图片记录显示为图片预览，任务结束后仍默认展开。点击图片可打开原图并缩放；加载失败显示重试入口。图片位于会话目录外时，服务端核对原始桌面工具调用，只授权该会话实际读取的具体图片。仅有普通消息中的外部图片路径不会授予访问权限；文件被移动或删除、虚拟机路径未映射时仍可能无法读取。

输入框显示当前模型与思考强度。唤起键盘后保留至少两行输入空间，审批卡收为可展开的提示，执行详情收起；展开执行详情时不重复堆叠审批卡，发送按钮保持可见。

页面使用常驻视图和统一 SSE 订阅，切换会话、设置、终端时保留原页面、草稿、阅读位置与展开状态；恢复时先显示缓存，再同步变更。断线重连不会删除绑定，业务写入发出后不自动重复发送。回前台同步且不自动弹键盘。新消息保持当前阅读位置，拖动时暂缓更新。右侧滑块可快速定位，圆形顶部／最新按钮可移动；下滑时隐藏顶部，反向滑动恢复。

## Git 与文件

会话向右滑动打开 Git，向左滑动或返回键回到会话。上半部分显示暂存／未暂存更改和差异，下半部分显示提交图；同一仓库共享提交草稿及待核对操作。支持暂存、取消暂存、提交、获取、仅快进拉取、推送、新建与切换分支，配色跟随应用主题。

会话信息中的工作目录支持浏览与切换目录、缓存和长按复制完整路径；正文文件链接也是预览入口。目录弹窗按会话保留，重新打开会直接显示上次读取的目录，同一会话内不再重复向电脑请求。会话信息会同时列出项目目录与会话工作目录，两者不同时可以据此判断路径来源。读取目录和文件不需要重建会话记录，因此预览明显更快。点击文件后会立即显示加载页，重复打开优先使用本地缓存。支持图片缩放、PDF 翻页与缩放、原生 Markdown、文本、离线 HTML、系统支持编码的音视频。电脑具备 Office 或 LibreOffice 时，Word、PPT、Excel（含旧版格式）在电脑本地转换成 PDF，手机保留版式查看；首次转换需要等待，后续复用文件修订缓存。现代 Office 格式在无法转换时可回退文字预览。支持分享／保存原文件和选择其他应用打开。手机不支持的格式会明确提示，避免点击后无响应。

文件预览只读取会话工作目录、项目目录或后端已授权引用，拒绝越界。较大文件和文档页面采用鉴权流式下载到手机私有缓存，不再受原 12 MB JSON 上限限制；重复打开先读缓存并用修订标识验证。可用空间不足会明确提示；文本最多渲染 300,000 字符，原文件仍可保存或交给其他应用。离线 HTML 可执行内嵌脚本，但不能访问网络、任意文件或应用密钥。Cowork 虚拟机未映射到电脑的文件可能无法读取。

## 悬浮窗与通知

在设置中启用并授予相应系统权限。可选择 App 前台是否显示，任务系统通知仍遵守前台抑制策略。

悬浮窗为无底板宠物，提供线条小狗、机器人和简洁把手。状态包括空闲、工作、思考、待回答、待审批、完成、错误、断线和睡眠；错误／审批优先于普通进度，首次同步与重复快照不重复触发提醒。重要事件短暂反馈，空闲及低电量降低帧率，窗口隐藏时停止绘制。

单击展开跟随宠物的气泡，双击进入当前活跃会话，长按打开锚定菜单；菜单包含打开应用／会话、四种显示模式、隐藏一小时和关闭悬浮窗。点击任务直接进入对应会话，点外部或再次点击宠物收起。宠物整体保持位置稳定，耳朵、爪子、眨眼及机器人手部按状态活动；任务气泡显示应用图标；气泡展开后固定方向，状态刷新不会让宠物和气泡左右跳动。过滤只有“正在思考…”等占位词的空内容。气泡与菜单在悬浮窗内部，支持边缘吸附、安全区域、方向变化与输入法避让。

四种模式为完整动作、仅重要事件、仅状态角标和静默；静默只隐藏窗口，不关闭连接。设置还可调整前台显示、吸附、气泡宽度、停留时间、动作速度和勿扰起止时间。

新的审批或提问属于需要用户决定的操作，除了让宠物做出提醒动作，开启通知时还会通过“待审批与待回答”渠道发送一条通知，点击进入对应会话。重复事件不会重复提醒，助手重启后也不会对已有事项再次提醒。

任务完成通知默认关闭。启用任务通知或悬浮窗后，绑定服务共用 SSE 接收源事件触发的状态更新；不显示“远程任务监控运行中”常驻通知，不定时补查内容。只有本机观察到执行过的任务结束才会发送完成提醒，电脑端改名、切换会话等操作不会误报。系统省电、强制停止和断网仍可能中断后台监控。回到 App 可恢复监控，不属于厂商云推送。


## 终端与桌面控制

会话信息中可打开独立终端，选择本机、WSL 或 SSH（使用电脑已有密钥）。命令只在点击运行时执行，切换会话保留输入与输出。手机多标签工作台已移除；Git 管理、工作目录与终端在会话信息底部使用统一的一行入口。

设置首页仅保留任务通知开关，移除二级通知页面和记录入口。连接详情入口显示电脑名称与系统，桌面应用使用统一设置行和居中操作弹窗。重新连接与启动／关闭／重启均保留在条目菜单，应用行不再重复显示重新连接按钮；桌面助手支持重新同步、关闭与重启，电源可开启任务结束自动关机。

## 个性化与验证

可选择 Catppuccin、Tokyo Night、Everforest 三套完整配色，并可选浅色、深色或跟随系统。主题只改变组件、文字、状态和代码配色，字体单独选择系统黑体、衬线宋体、紧凑黑体或等宽；圆角与排版一致。公开参考见[配色说明](mobile-palettes.md)。会话列表和消息页分别支持背景图片、不透明度及清除功能。

设置分为连接、外观与背景、通知与宠物、电脑。“连接详情”位于连接分组，永久连接网络设置合入详情；详情不重复显示扫码入口或当前线路。“外观与背景”有“外观与主题”“背景与阅读”两个子项。任务通知、解除绑定等设置行提供图标，版本号在底部居中。左上角客户端名称在页面内展开或收起操作列表，宽度最多 176dp、窄屏不超出可用区域；返回键也可收起。

Python、JavaScript 和 Android 回归测试保留在 `tests/`，执行方法见[构建说明](native-build.md#验证)。示例截图使用模拟器测试数据；实体手机和不同桌面版本的行为仍需结合实际环境确认。

2.2.5 R4：项目目录标题增至 17sp，项目头行收紧到 36dp，缩小与下方会话条的距离。更换主题、显示模式或字体后仍停留在“外观与主题”，恢复原滚动位置。桌面只改变模型、思考强度或停止状态时也推送更新；手机阅读历史、滚动期间仍更新这些状态和模型按钮。

2.2.5 R3：会话标题最多两行，单行标题的条目高度为 1.5 行，双行标题为 2.5 行；条目间留半行空隙，移除直线分隔，保持圆角卡片完整。连接详情隐藏当前电脑历史临时线路、过滤过期项，并按电脑与连接类型去重；底层凭据仍保留。悬浮气泡的应用与状态采用次级文字，会话名更大加粗且使用辅助色，分隔线下方正文保留正常字重。
