# 手机功能说明

适用于 Android 原生版 2.0.11。首次配对与客户端接入见[快速开始](quick-start.md)，示例截图见 [README](../README.md#界面示例)。

## 会话与项目

底部切换 Claude、Codex、DeepSeek。每个页面独立提供新建、刷新、搜索和项目分组；设置可隐藏不使用的页面。最近会话显示项目目录，执行中的 Codex / DeepSeek 会话显示运行状态。归档会话集中在列表末尾“归档”的弹窗中。

点击客户端页标题可启动、关闭或重启该客户端。新建 Claude 会话可选 Code 或 Work（Cowork）。明确点击 Codex 会话时会打开对应桌面任务，后台读取和返回前台不会反复切换桌面。

## 输入与任务控制

| 入口 | 功能 |
| --- | --- |
| 模型与思考强度 | 根据后端能力选择，保存后回读核对。Claude 选项不全时可在桌面打开模型菜单后刷新。 |
| 审批 | 显示后端提供的权限选项；桌面审批和提问可在手机回复，支持选项、自由输入和基础表单。 |
| 插件 | Codex 按已安装插件整包选择；DeepSeek 显示技能与组件状态，具体选项取决于桌面。 |
| 模式 | Codex 支持普通／计划模式，以及目标设置、暂停、继续和清除；Token 预算仅在填写时提交。 |
| 附件 | 单次最多四张图片，支持只发图片。 |
| 发送／停止 | 执行中无输入时停止，有输入时加入队列。队列可撤回编辑、删除或立即发送。 |

队列保存在电脑，任务结束后依次执行。写入使用独立请求编号，结果不确定时暂停后续发送，通过原请求查询结果，避免重复任务。

发送按钮外圈顺时针显示上下文占用，长按可查看已用／最大 tokens，75% 和 90% 时变色。只有可信统计才显示用量：Codex 使用最新一轮统计，Claude 接口可能返回空值，DeepSeek 当前没有可用统计；未知显示灰环与“—”。

## 阅读与执行记录

消息支持 Markdown、围栏代码、diff 与图片。长按可复制整条消息、选择部分文字、引用或分享；选字期间暂缓重绘。

执行记录按需折叠，保留可见思考摘要、计划、文件变化和实际工具内容；Codex 命令及通用通信包装被过滤。代码增加／删除统计来自执行记录累计变化，不等于 Git 的最终净差异。任务结束后执行记录再次折叠。

会话缓存减少切页重载；回前台立即同步并保留草稿，不自动弹键盘。新消息保持当前阅读位置，拖动时暂缓更新。右侧滑块可快速定位，圆形顶部／最新按钮可移动；下滑时隐藏顶部，反向滑动恢复。

## Git 与文件

会话向右滑动打开 Git，向左滑动或返回键回到会话。上半部分显示暂存／未暂存更改和差异，下半部分显示提交图；同一仓库共享提交草稿及待核对操作。支持暂存、取消暂存、提交、获取、仅快进拉取、推送、新建与切换分支，配色跟随应用主题。

会话信息中的工作目录支持浏览与切换目录、缓存和长按复制完整路径；正文文件链接也是预览入口。支持图片缩放、PDF 翻页、原生 Markdown、文本与离线 HTML，也可分享给其他应用。

文件预览只读取项目目录或后端已授权的会话引用，拒绝越界与超过 12 MB 的文件；文本最多渲染 300,000 字符。离线 HTML 可执行内嵌脚本，但不能访问网络、任意文件或应用密钥。Cowork 虚拟机未映射到电脑的文件可能无法读取。

## 悬浮窗与通知

在设置中启用并授予相应系统权限。App 可见时隐藏悬浮窗并抑制任务通知。

悬浮窗折叠时可拖动，显示“执行中”“待审批”“待回答”“就绪”或“离线”；展开后显示客户端、状态、会话与消息。新回复正文触发沿边框流动的彩色动画，首次同步、重复轮询、思考、工具步骤和纯状态变化不会触发。正文动画没有声音、振动或额外系统通知。新审批／提问可单独触发提醒，点击进入对应会话。

任务完成通知默认关闭，通过进程存活时的轮询与系统作业补查实现。系统省电、强制停止、断网及后台限制可能中断监控；进程回收后可能延迟约 15 分钟，不属于厂商云推送。

## 个性化与验证

可选白色、深色、浅绿、海蓝、紫藤、沙色和午夜主题。设置还包括页面显隐、设备网络、已保存连接、缓存与桌面助手控制。

Python、JavaScript 和 Android 回归测试保留在 `tests/`，执行方法见[构建说明](native-build.md#验证)。示例截图使用模拟器测试数据；实体手机和不同桌面版本的行为仍需结合实际环境确认。
