# 常见问题

## 没有服务器和域名能用吗？

可以。默认的临时扫码连接通过 Cloudflare Quick Tunnel 提供 HTTPS 入口，无需自行准备服务器、域名或路由器端口转发。

## 必须安装 Tailscale 吗？

临时连接和自有服务器永久绑定都不需要 Tailscale。选择 Tailscale 永久绑定时，两端需加入同一网络，可使用内置组件。详见[设备网络](tailscale-integration.md)和[自有服务器部署](azure-server.md)。

## 二维码过期或绑定失效怎么办？

二维码 5 分钟有效、单次使用，过期后重新生成。临时凭据 24 小时有效；主动关闭临时入口或退出后台服务会使其失效，届时重新扫码即可。隧道进程自行中断不会再吊销已配对凭据，但临时地址变化后仍需重新扫码。永久绑定可跨重启保留，但需要原网络身份仍有效、两端在线且网络权限允许访问。

## 手机登录密码在哪里？

当前 Android 原生版扫码即可配对，无需手机登录密码。连接失效时，在电脑助手重新生成二维码并扫码配对。

## 关闭电脑助手窗口后还能用吗？

可以，关闭窗口会保留后台服务。电脑休眠、关机或通过系统托盘退出后台服务后则无法访问；手机不能启动已经停止的服务。

## Claude 一直没有连接成功怎么办？

确认 Claude Desktop 已登录，工作目录已按桌面要求受信任，再点击手机 Claude 页标题中的“启动”。自动输入连接脚本时不要切换焦点；按 Esc 会中止。失败后保留的窗口可用于检查错误。模型选项不全时，在桌面打开模型菜单后刷新手机选项。普通云端 Chat 不受支持。

## DeepSeek 没有出现会话怎么办？

这里支持的是 DeepSeek Harness 桌面客户端。确认已经安装，首次配置本地 Host 插件后正常重启 Harness，让插件加载，再刷新手机页面。

## 为什么通知延迟、悬浮窗不出现？

请同时更新两端到 2.2.5，在手机设置中启用功能并授予通知或悬浮窗权限。本版由原生桌面事件和文件变更通知触发 SSE 更新；手机不定时补查内容，也不显示常驻监控通知。保活帧只用于判断断线，不会触发内容刷新。系统省电、强制停止和断网仍会影响后台连接。回到 App 可重新启动监控；悬浮窗是否在 App 前台显示由设置决定，任务提醒仍在前台抑制。

## 固定地址健康检查正常，为什么手机仍无法连接？

`/healthz` 只表示服务器 Nginx 在线。桌面助手及 SSH 转发也需要运行，`/api/gateway` 应返回当前电脑身份；502 通常表示转发未建立。检查桌面日志中的 `ssh-tunnel-server.log`，以及服务器证书、80/443 入站规则和电脑网络代理。不要把远端转发端口 18787 直接开放到公网。

## 文件为什么无法预览？

文件必须属于项目目录或后端已授权的会话引用。较大文件会流式下载到手机私有缓存；手机可用空间不足时会提示。Word、PPT、Excel 的版式预览需要电脑上的 Office 或 LibreOffice，首次转换可能等待几秒；Cowork 虚拟机中没有映射到电脑的文件也可能无法读取。离线 HTML 不加载网络资源，依赖外部资源的页面可能显示不完整。

## 更新 APK 提示签名不兼容怎么办？

覆盖安装需要相同的应用签名。自行构建时保留 `.local/signing/` 中的签名材料。卸载会清除应用数据，处理之前先保存需要的文件；安装后可能需要重新配对。

## 源码和构建工具在哪里？

适配源码位于 `coding_remote/` 与 `claude_bridge/`，Android 原生代码与构建脚本位于 `packaging/`。当前构建仍依赖指定的上游安装包，并非完整上游源码工程；环境要求见[构建说明](native-build.md)。

## 支持 iPhone 或其他电脑系统吗？

当前修改版交付 Windows x64 与 Android；旧上游文档中的 IPA 不属于这一原生版。它是社区工具，与 OpenAI、Anthropic、DeepSeek 无隶属关系，也不提供账号或模型额度。

## 扫码提示“仅支持 HTTP POST Responses”或临时二维码无法生成？

已定位到 Windows 8787 端口被模型代理服务占用时，旧助手的端口复用会让配对请求进入该服务。新版改为独占监听，冲突时自动换用可用端口，无需手动修改转发端口。更新两端，从系统托盘退出旧助手后重新打开并刷新二维码，再扫描新二维码。
