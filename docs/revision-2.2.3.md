# 2.2.3 修订记录

2026-11-08，Windows / Android 本地构建。版本号继续保持 **2.2.3**，本次覆盖此前同版本安装包；文件及 SHA-256 见[版本记录](releases.md)。两端需要同时更新。

## 本次继续完成的调整

- 修复返回缓存会话后“执行详情”无法展开：页面切换只释放当前引用，保留原页面拥有的详情面板。执行条居中显示步骤数、文件数、待处理数，以及绿色增加量、红色删除量。
- 删除会话列表左侧竖条；消息标题下不再重复显示会话目录。目录仍可从会话信息查看。
- 删除 Windows 工作台、通知中心及对应后台会话订阅。保留概览、账号与模型、日志、设置四页。未变化的账号快照及日志不重建控件，窗口缩放只在布局档位变化时更新导航。
- 删除手机多标签工作台；会话信息保留 Git、工作目录，新增独立终端。终端命令输入、输出及页面在切换会话时保留，只在点击运行时执行。
- Git 首先解析会话目录；该目录没有仓库时尝试该会话关联的项目目录。普通非 Git 目录显示中文说明，不再直接抛出 `fatal: not a git repository`。
- 统一会话长按、筛选、设置选择、确认及编辑弹窗的底部面板、标题、关闭入口和动作行。文件预览继续使用适合阅读的全屏界面。
- 设置首页删除搜索框，绑定电脑卡显示电脑名称和系统；通知记录合并进任务通知；桌面应用使用统一设置行和操作弹窗。
- 两端加入经典、纸页、紧凑三种主题风格，分别调整圆角、边框、表面与字体等。手机支持分别导入会话列表和会话消息背景、设置 0–100% 不透明度、清除背景。图片复制到私有目录并限制解码尺寸。
- 新建会话立即打开面板，再异步读取项目，避免点击后等待空白。创建请求仍通过原请求编号核对，不重复提交。
- 界面客户端名称统一为 ChatGPT；保留连接协议、安装包标识和历史路径所需的内部名称。

## 实时更新与宠物

- 手机根据整个 SSE 通道的心跳判断健康状态，未变化的会话不再因为“六秒没有新内容”而触发 HTTP 轮询。缺失初始快照或通道失效时仍有回退，恢复后继续使用事件连接。
- Windows 使用系统文件变更通知观察 ChatGPT 会话目录及数据库，通知共享事件总线补读变化。会话修订包含完整记录文件的大小和修改时间，因此工具记录、代码与正文变化均能触发更新。草稿和置顶写入主动使相关订阅失效。
- 不提供稳定事件接口的后端仍保留有界的兼容采集；文件监听不可用时有回退。健康检查及低频校准仍存在，未声称所有来源都能完全取消轮询。
- 参考 dsh-Go 的按状态播放、固定锚点和局部动作方式，为现有小狗加入耳朵、爪子、眨眼动作，为机器人补充工作手部动作。保留待处理、完成、休眠及触摸反馈；宠物整体位置保持固定。
- 悬浮任务气泡显示对应应用图标。左侧、右侧、中间位置打开、刷新和收起均保持宠物与气泡锚点；空思考占位内容继续过滤。

## 本版保留的阅读修复

手机原生 Markdown 表格支持横向滚动、对齐和分页表头。桌面读取图片记录默认显示缩略图，支持原图缩放、失败重试及大文件鉴权下载；工作目录外图片仍只根据本会话真实工具调用逐文件授权。

撤回输入提示不常驻，代码变更路径单行省略；键盘弹出时保留至少两行输入空间，审批卡收起，发送按钮保持可见。
