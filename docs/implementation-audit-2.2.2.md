## 文件打开

`NativePreview` 提供即刻加载页、取消、失败重试、缓存优先和修订验证。大文件经鉴权流式下载到私有缓存，摆脱原 12 MB JSON 限制。图片和 PDF 支持缩放，PDF 可翻页；支持 Markdown、文本、离线 HTML 和系统可解码音视频。Word、PPT、Excel 由电脑 Office／LibreOffice 本地生成 PDF 保留版式，较大的 PDF 也流式传输。现代 Office 在无法转换时回退有界 XML 文字提取；分享／其他应用打开使用原文件及临时 URI 授权。

`FilePreviewRegression` 已验证 Office PDF 磁盘打开、翻页、原文件操作、DOCX 文字回退和其他格式交接；`FeatureRegression` 覆盖 PNG／PDF／HTML／Markdown。电脑实际转换 DOCX、PPTX、XLSX 均成功，首轮约 5–8 秒，重复读取复用缓存。点击反馈即时出现；首次跨网传输和文档转换受文件大小、网络、电脑软件与手机能力影响，不承诺任何文件零延迟完成。

## 依赖与验证边界

ChatGPT 此处指桌面本地可发现的会话；没有增加 ChatGPT 网页云端历史账号连接器。模型、额度／上下文数据依后端是否提供，未知值不伪造。API、工作台 SSH / WSL、外部通知需用户自己的账号或现有环境；本次用隔离夹具和模拟响应验证相关路径，没有使用真实凭据发送通知或修改个人会话。实体手机、各厂商后台限制及所有桌面客户端版本的跨公网行为未能穷举。Claude 含图片消息需在电脑编辑以保留附件；编辑不会回滚文件修改。
