coding远程助手 2.2.5 — local modified build, 2026-11-10.

Based on Codex Mobile Assistant Windows 1.6.23 and Android 1.0.19.
This is not an official upstream release.
The interface and functional changes of this modified build are listed in
docs/releases.md.

Windows: original bundled Python runtime, Codex bridge, libraries, icons and
cloudflared are retained. The launcher is replaced with a native application.
cloudflared is executed only after its bytes match the digest recorded at build
time. Original web assets are removed. QR pairing uses expiring one-use secrets
through a temporary HTTPS tunnel, persistent Tailscale binding, or a fixed
self-hosted HTTPS entrance with supervised reverse SSH forwarding.
The Windows gateway binds exclusively and selects a free port on conflict;
All QR routes use the actual listener port. Personal server settings and SSH
private keys are not bundled. Native source events and Windows filesystem
notifications trigger collection and SSE delivery; healthy content is not polled.
Claude uses the existing
Desktop session APIs via a local JSON file connector. A bundled keyboard helper
opens normal DevTools and types the connector using SendInput only after
verifying Claude Console focus. The connector has no comment header or file
signatures; input is paced without rereading each typed segment. No clipboard
or debug launch flags are used.

Android: native Claude, Codex, DeepSeek and Settings screens replace the original
web session UI. Offline HTML and image preview still use a restricted WebView
with network loads disabled. Original branding assets and scanner are retained.
CaptureManager's two missing AndroidX permission calls use the Android platform
equivalents. The camera permission flow is retained.
Package ID: io.github.abyxs.codingremote.
It uses a local signing key and coexists with the upstream app.
Enabled notifications or overlays share a bound monitoring service without an
ongoing notification or periodic status job. Android may stop background processes;
reopening the app restores the event connection. Transport keepalive frames detect
broken connections only and do not trigger content collection or UI refresh.

Original licenses and third-party notices remain applicable. ZXing Android
Embedded and ZXing Core are licensed under Apache License 2.0. No Claude
Desktop executable is bundled. Private Desktop APIs are version dependent.

UI references: codex-mobile-bridge and dsh-Go
(d5ad25c5bc4c66ecacee76b3c5378db45e1db3fa). The settings interface is an
independent native implementation using this project's widgets and pet art.
No DSH Go brand or reserved mascot assets are redistributed. Android does not
bundle JSch or EdDSA-Java. Claude and Codex message editing uses the existing
desktop session APIs, with history checks and request deduplication.
